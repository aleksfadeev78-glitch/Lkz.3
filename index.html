Telegram-уведомления бесплатно
Инструкция по настройке Telegram

1. В Telegram найдите @BotFather.

2. Отправьте ему команду /newbot и создайте бота.

3. Скопируйте полученный токен в поле выше.

4. Найдите вашего нового бота и отправьте ему сообщение /start.

5. Чтобы узнать Chat ID, откройте в браузере:
https://api.telegram.org/botВАШ_ТОКЕН/getUpdates

6. Найдите блок вида: "chat":{"id":123456789}. Это ваш Chat ID.

7. Вернитесь сюда, вставьте Chat ID и нажмите «Тест».

Важно: токен даёт доступ к боту. Не публикуйте страницу с токеном в открытом доступе.
